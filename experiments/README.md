# Experimente

Eine JSON-Datei je Auswertung, benannt `<Auswertung>_<Datum>.json`,
erzeugt von den Programmen unter `src/analyze/`. Dazu
`kostenschaetzung.md` (Kostenschaetzung vor dem ersten
kostenpflichtigen Lauf, Grundlage von E8).

Modell, Prompt-Version, Parameter und Datensatzstand eines Laufs stehen
im Manifest der zugehoerigen Extraktion unter `data/processed/`, die
Begruendungen in `docs/entscheidungen.md`.
