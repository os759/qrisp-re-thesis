# Dokumentation

- `anforderungen_openai_claude.md` Lesefassung aller rekonstruierten
  Anforderungen (OpenAI-Volllauf, danach Claude-Vergleichslauf), ohne
  Belegzitate. Abgeleitet aus den JSONL-Dateien unter `data/processed/`.
- `ki-protokoll.md` Protokoll des KI-Einsatzes
- `entscheidungen.md` Designentscheidungen mit Begruendung und Datum
- `formatauswahl.md`, `formatprobe_protokoll.md` Auswahl des
  Anforderungsformats (FF2)
- `findings_*.md`, `sample_*.md`, `regel3_volllauf.md`,
  `ollama_protokollauszug.md` Befunde, Stichproben und Protokollauszuege
  zu einzelnen Arbeitsschritten

Die Literaturmatrix liegt in `literatur/literaturmatrix.md`.
