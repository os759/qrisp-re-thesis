# Evaluation

- `instrument/` Bewertungsbogen, Skala, Anweisungen fuer Bewertende
- `responses/` ausgefuellte Bewertungen. NICHT versioniert (personenbezogen).
- `sample/` leer. Die Stichproben liegen in `docs/sample_*.md` und
  werden von `src/analyze/draw_sample.py` erzeugt.

Evaluationsdesign: reduzierte Evaluation durch den Betreuer,
ergaenzt um eine dokumentierte Selbstbewertung. Abweichung vom
Exposé, mit dem Professor abgestimmt, in den Limitationen auszuweisen.
