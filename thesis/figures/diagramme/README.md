# Abbildungen

Mermaid-Quellen der fünf Abbildungen der Arbeit. Die PDF-Dateien in
`thesis/figures/` werden mit `sh build.sh` aus diesen Quellen erzeugt
(Mermaid CLI 11.4.2, Darstellung `neutral`, Einstellungen in
`mermaid.json` und `mermaid_seq.json`).

| Datei | Abbildung | Inhalt |
|---|---|---|
| `d1_pipeline.mmd` | 4.1 | Stufen der Pipeline mit Programmen und Zwischenergebnissen |
| `d4_belegstaerke.mmd` | 4.2 | Berechnung der Belegstärke |
| `d2_aufruf.mmd` | 5.1 | Ablauf eines Laufs im Aufrufprogramm |
| `d3_pruefung.mmd` | 5.2 | Prüfung einer Antwort und Zuordnung abgelehnter Zitate |
| `d7_gap.mmd` | 6.1 | Ablauf und Ergebnis der Gap-Analyse |
