# Prompt-Vorlagen

Je Fassung zwei Dateien in diesem Ordner: `extraction_system_vN.md` (feste Systemanweisung) und `extraction_user_vN.md` (Vorlage der Nachricht).
Eine bereits fuer einen Lauf verwendete Version wird nicht mehr
veraendert, sondern es wird eine neue angelegt.

Jeder Experimentlauf verweist auf die verwendete Prompt-Version.
