# Daten

- `raw/` unveraenderte API-Antworten. NICHT versioniert.
- `interim/` Zwischenstaende der Aufbereitung. NICHT versioniert.
- `processed/` aufbereiteter Korpus als Eingabe der Extraktion. Versioniert.

Jeder Datensatzstand wird in `MANIFEST.md` mit Erhebungszeitpunkt,
Umfang und Pruefsumme dokumentiert.
